# 数据字段与口径

本文档定义字段名、单位、事件身份、存/算分离和 patch 语义。采集与请求范围见 `Skill行为说明.md`。证券宇宙、ST、20%/30% 限制、连板连续性和统计公式见 `资本市场复盘指标说明与统计口径.md`。

## 1. 单位

写入 CLI 前换算为存储单位。`get` 返回存储单位；展示换算见 `SKILL.md`。

| 类别 | 存储 | 写入换算 |
| --- | --- | --- |
| 市场成交额、市值、融资余额 | 元 | 亿元 × `1e8`，万亿元 × `1e12` |
| 百分比类原子字段（中位数涨跌幅等） | 小数，例如 `0.1875` | `18.75%` → `0.1875` |
| 指数点位、PE、平均股价 | 原单位数值 | 原样 |
| 个股成交额、竞价额 | 元 | 万元 × `1e4`，亿元 × `1e8` |
| 个股价格 | 元/股 | 原样 |
| 个股换手率 | 小数，例如 `0.125` | `12.5%` → `0.125` |

融资余额按其业务交易日归属写入对应交易日，即使实际要到 T+1 才公布。不得拿前一日余额冒充当日数据。北交所融资余额页面以万元展示时，乘以 `10000` 后按元提交。

`get` 返回的 `summary` 中 `broken_rate_pct`、`streak_rate_pct` 和指数 `change_pct` 已经是百分数数值（如 `18.75`），写入时不要把它们再当原子字段提交。

## 2. 总体复盘原子字段

同一交易日只有一行。来源类型用于构造写入范围，不表示数据库会取数。

| 字段 | 类别 | 存储 | 来源 |
| --- | --- | --- | --- |
| `pullback_count` | 市场宽度 | 可空整数 | 尽力获取 |
| `median_change_pct` | 市场宽度 | 可空小数 | 尽力获取 |
| `advancing_count` | 市场宽度 | 可空整数 | 尽力获取 |
| `declining_count` | 市场宽度 | 可空整数 | 尽力获取 |
| `margin_balance_sh` | 两融 | 元，可空 | 尽力获取 |
| `margin_balance_sz` | 两融 | 元，可空 | 尽力获取 |
| `margin_balance_bj` | 两融 | 元，可空 | 尽力获取 |
| `sh_index_close` / `sh_index_prev_close` | 指数 | 点位，可空 | 自动承诺，代码 `000001` |
| `sz_index_close` / `sz_index_prev_close` | 指数 | 点位，可空 | 自动承诺，代码 `399001` |
| `cy_index_close` / `cy_index_prev_close` | 指数 | 点位，可空 | 自动承诺，代码 `399006` |
| `turnover_amount_sh` | 成交额 | 元，可空 | 尽力获取 |
| `turnover_amount_sz` | 成交额 | 元，可空 | 尽力获取 |
| `turnover_amount_cy` | 成交额 | 元，可空 | 尽力获取；已包含在深圳成交额中 |
| `turnover_amount_bj` | 成交额 | 元，可空 | 尽力获取 |
| `total_market_cap` / `float_market_cap` | 市值 | 元，可空 | 尽力获取 |
| `pe_sh` / `pe_sz` / `pe_cy` / `pe_all` | 估值 | 原单位，可空 | 尽力获取；分市场 PE 代码同对应指数 |
| `avg_stock_price` | 平均股价 | 原单位，可空 | 尽力获取 |

「补齐两融」范围是上述三项融资余额。指数必须成对提交当日收盘与前收盘；只取得一侧则该指数不进入本次 patch。

`null` 表示缺失，`0` 表示数量或金额为零。数量字段不得用 `0` 表示「未取得」。

## 3. 读取后统计，不可独立入库

由 `get` 的 `summary` 或 `ladder` 返回，不能作为 `save-review` 字段提交：

- `effective_limit_up_count`、`limit_up_20pct_count`、`limit_up_broken_count`、`down_opened_count`、`down_closed_count`
- `broken_rate_pct`、`limit_up_down_ratio`
- `first_board_count`、`streak_board_count`、`streak_rate_pct`、`highest_board`、`highest_board_representatives`、`streak_by_height`
- `margin_balance_total`、`turnover_amount_total`
- 指数 `change_points` / `change_pct`
- `ladder` 中的分组、名单、`auction_ratio`、`open_change`

用户只提供「今天最高板是四板」等汇总值而没有个股事件时，不写入，提示需要个股触板事件。

成交额合计 = 上海 + 深圳 + 北京；创业板成交额不重复计入。融资余额合计三项任一缺失则合计为空。

## 4. 事件身份与核心字段

唯一键：`(trade_date, market, code, direction)`。`market` 为小写 `sh | sz | bj`，`code` 为 6 位 ASCII 数字字符串（`^[0-9]{6}$`），不接受全角数字。写入必须同时提交 `market` 和 `code`，不猜测市场。展示时只显示 6 位代码。

| 字段 | 约束 |
| --- | --- |
| `name` | 非空字符串 |
| `direction` | `up` 或 `down`，属于唯一键 |
| `closed_at_limit` | 布尔；记录存在即表示盘中曾触板 |
| `limit_rate_bp` | `1000`、`2000` 或 `3000` |
| `streak_height` | 非负整数，每条事件都必须提交 |

| `direction` | `closed_at_limit` | 含义 |
| --- | --- | --- |
| `up` | `true` | 有效涨停 |
| `up` | `false` | 涨停炸板 |
| `down` | `true` | 收盘跌停 |
| `down` | `false` | 打开跌停 |

`streak_height`：用户提供连板数则检查为整数后原样使用；用户未提供时按指标附录的连板连续性规则计算后写入。炸板和跌停写 `0`。数据库不回溯或校验该整数。

方向属于唯一键。由涨停改为跌停（或相反）必须调用 `replace-direction`，在同一事务中删除旧方向并写入新事件，不能只改 `direction`，也不能先删后写。

空事件列表是 no-op，不表示清空当日名单。

## 5. Patch 语义

**总体复盘原子字段**

| 输入 | 结果 |
| --- | --- |
| 未提供 | 保持原值；新记录保持 `null` |
| 具体值，包括 `0` | 更新 |
| 显式 `null` | 清空 |
| 指定来源未给出的字段 | 保持原值，不清空 |

**涨跌停事件**

| 输入 | 结果 |
| --- | --- |
| 同一身份再次保存 | 覆盖该事件核心字段 |
| 空列表 | no-op |
| 单股删除 | `delete-event` |
| 方向变化 | `replace-direction` |

**事件明细**

| 输入 | 结果 |
| --- | --- |
| 标量未提供 | 保持原值 |
| 标量具体值，包括 `0`、`false` | 更新 |
| 标量显式 `null` | 清空 |
| 多值未提供 | 保持原列表 |
| 多值非空列表 | 按输入顺序整体替换 |
| 多值 `[]` | 清空列表 |
| 空 `details` 数组 | no-op，不表示清空当日梯队 |

明细只能关联已保存事件；父事件不存在时整批失败，不得只创建明细。

## 6. 事件明细字段

| 字段 | 存储口径 |
| --- | --- |
| `previous_turnover_amount` | 上一交易日全天成交额，元，有限非负 |
| `auction_amount` | 开盘集合竞价成交额，元，有限非负 |
| `previous_close` | 昨日收盘价，元/股，有限且大于 0 |
| `open_price` | 今日开盘价，元/股，有限且大于 0 |
| `turnover_amount` | 当日全天成交额，元，有限非负 |
| `turnover_rate` | 换手率，小数，有限非负 |
| `is_leader` | `true` / `false` / `null`；不由板高自动认定 |
| `note` | 字符串或 `null`；空白规范为 `null` |
| `sectors` | 有序非空字符串；所有方向可用 |
| `limit_up_reasons` | 有序非空字符串；只允许 `direction=up` |

多值项去除首尾空白，拒绝空字符串，完全重复值只保留第一次出现的位置，不合并近义词。跌停事件写入 `limit_up_reasons` 时整批失败。`replace-direction` 从 `up` 改为 `down` 时迁移明细标量和 `sectors`，不迁移 `limit_up_reasons`。

派生字段读取时计算，不接受直接写入：

- `auction_ratio = auction_amount / previous_turnover_amount`
- `open_change = open_price / previous_close - 1`

任一输入缺失或分母为 `0` 时为 `null`。

## 7. 最小写入示例

日期通过 CLI `--date` 传递，不要放进 JSON。`save-events` 接受对象包装或直接数组。

```bash
python3 "<skill-dir>/scripts/cli.py" save-events --date 2026-08-21 --input -
```

```json
{
  "events": [
    {
      "market": "sh",
      "code": "600519",
      "name": "贵州茅台",
      "direction": "up",
      "closed_at_limit": true,
      "limit_rate_bp": 1000,
      "streak_height": 4
    }
  ]
}
```
